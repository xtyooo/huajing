# 满聚管理员模型映射兼容

内置六个模型只作推荐。后台配置的新模型名、别名映射（例如 `wan3.0-video-prime`）直接提交上游，不受模型白名单限制。

用户继续调用标准视频接口。已知 `wan3.0-i2v`、`wan3.0-prime-i2v` 沿用 `first_frame` 图片角色；其余模型默认使用 `reference_image`、`reference_video`、`audio`。显式 `video_config.reference_mode=start_frame` 或 `reference_mode=start_frame` 可为新模型选择首帧角色。素材顺序、重复项和显式 `prompt_extend:false` 保留。旧 t2v 模型带素材时也转发素材，由上游判断能力。

提示词长度、素材数量、音频是否需要图片、模型时长和画幅支持范围交由上游校验。仍校验 JSON 结构、非空提示词、公共 HTTPS 素材地址、冲突字段和通用计费时长安全范围（1–3600 秒）。当前协议不表达尾帧角色，因此首尾帧输入明确拒绝。

本次不迁移满聚的历史计费规则：分辨率每秒定价和原有时长/分辨率倍率保持不变。分辨率仍要求 480P、720P、1080P，避免未配置的新清晰度落入旧价格兜底。时长超过原文档的 30 秒也会按现有价格正确计费，不会因放开能力限制成为零计费。历史名称相关价格行为的迁移需单独核对后台配置。
