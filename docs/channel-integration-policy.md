# 渠道接入长期约定

用户于 2026-09-22 确认。后续新增渠道及相关重构遵循本约定；
旧渠道文档中的型号限制和名称计费逻辑只描述现状，不能作为新接入模板。

## 模型与能力

- 模型名称、公开别名和上游映射由管理员在后台配置。
- 内置模型列表只用于推荐和展示，不作为准入白名单；支持手动配置或从上游获取新模型。
- 不因模型名称未收录、上游改名或文档中的临时库存提示拦截请求。
- 模型支持的时长、分辨率、画幅、素材数量、生成模式等由上游校验；
  不把文档快照写成永久的本地能力限制，也不为未知模型设置猜测的能力上限。
- 上游拒绝时，通过现有错误协议给出可诊断且脱敏的原因。

## 计费

- 按次／按秒、价格以及必要的倍率由后台明确配置；价格读取公开模型配置。
- 禁止根据模型名称、前缀或后缀（如 `-PerSecond`）推断计费方式。
- 单纯修改上游模型名称，不应改变计费模式或金额。
- 后台现有配置不足以表达所需计费模式时，应补齐配置能力，不能以名称猜测替代。
- 按次不叠加时长；按秒使用经过安全校验的时长，只乘一次；
  保留既有分组倍率和显式“跳过秒数”语义，禁止零价或重复计费。

## 适配器职责与保留校验

- 用户侧沿用画境标准协议，适配器负责字段、类型、素材结构和响应状态转换。
- 通用素材列表兼容单个字符串与字符串数组，保持顺序；不能静默丢弃素材或改写提示词。
- 保留 JSON 类型、协议结构、鉴权、任务归属、公开／私有ID隔离、
  SSRF、资源大小和计费溢出边界等通用安全校验。
- “交给上游校验能力”不等于任意字段无筛选透传：
  协议确实无法表达的输入应明确说明或返回错误，不应伪造支持。
- 继续遵守视频缓存契约：缓存中进行中/99%，缓存成功且有稳定URL后成功/100%。

## 验收

1. 未出现在内置列表的新模型可通过管理员配置提交。
2. 修改上游模型名称但保持后台价格配置不变，计费结果不变。
3. 已知模型更新能力后，不被旧文档中的本地能力表挡住。
4. 错误结构、安全边界、按次／按秒及缓存状态回归测试仍通过。
